# CampusAI

CampusAI is an AI-powered student assistance platform developed using Microsoft Power Platform.

## Project Overview
This project includes:
- 2 AI Agents created in Microsoft Copilot Studio
- 1 PowerApps application for student interaction
- Power Automate integrations for workflow automation

## Features
- Student query assistance
- Smart AI-based responses
- Campus-related information support
- Interactive PowerApps interfa
- Automated workflows and notifications
## Technologies Used
- Microsoft Copilot Studio
- Power Apps
- Power Automate
- Power Platform
